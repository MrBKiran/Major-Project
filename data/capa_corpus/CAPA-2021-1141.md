# CAPA-2021-1141

- **Component:** radiator
- **Plant:** Pithampur
- **Batch:** BATCH-2021-Q4-STD
- **Opened:** 2021-11-04
- **Status:** open

## Defect mode
Radiator — core tube leak

## Root cause
A revised O-ring specification was released to production before the validation build completed.

## 5-Why
1. Why did the radiator fail? Observed core tube leak.
2. Why did that occur? Deviation traced to the final-assembly station.
3. Why was the deviation present? A revised O-ring specification was released to production before the validation build completed.
4. Why was it not detected? The existing control plan had no gate for this characteristic.
5. Why was there no gate? The FMEA did not rank this failure mode above the action threshold.

## Corrective action
Recall-inspect the affected lot and replace the component under warranty.

## Preventive action
Introduce SPC monitoring on the final-assembly torque with automatic line stop.
