# CAPA-2021-1088

- **Component:** radiator
- **Plant:** Nashik
- **Batch:** BATCH-2021-Q2-STD
- **Opened:** 2021-03-23
- **Status:** closed

## Defect mode
Radiator — end tank crimp seep

## Root cause
A revised housing specification was released to production before the validation build completed.

## 5-Why
1. Why did the radiator fail? Observed end tank crimp seep.
2. Why did that occur? Deviation traced to the press-fit station.
3. Why was the deviation present? A revised housing specification was released to production before the validation build completed.
4. Why was it not detected? The existing control plan had no gate for this characteristic.
5. Why was there no gate? The FMEA did not rank this failure mode above the action threshold.

## Corrective action
Recall-inspect the affected lot and replace the component under warranty.

## Preventive action
Add a dimensional gate at incoming inspection for the housing.
