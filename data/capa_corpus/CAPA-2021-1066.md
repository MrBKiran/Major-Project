# CAPA-2021-1066

- **Component:** alternator
- **Plant:** Haridwar
- **Batch:** BATCH-2021-Q1-STD
- **Opened:** 2021-03-15
- **Status:** monitoring

## Defect mode
Alternator — regulator failure

## Root cause
A revised shaft specification was released to production before the validation build completed.

## 5-Why
1. Why did the alternator fail? Observed regulator failure.
2. Why did that occur? Deviation traced to the engine-dress station.
3. Why was the deviation present? A revised shaft specification was released to production before the validation build completed.
4. Why was it not detected? The existing control plan had no gate for this characteristic.
5. Why was there no gate? The FMEA did not rank this failure mode above the action threshold.

## Corrective action
Rework the affected units at the regional service network.

## Preventive action
Introduce SPC monitoring on the engine-dress torque with automatic line stop.
